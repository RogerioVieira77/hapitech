## 1. Visão do Produto

### 1.1 O que é hapitechAI

**hapitechAI** é uma plataforma SaaS para criação, gerenciamento e operação de **agentes de IA conversacionais**.
Empresas usam a plataforma para configurar agentes que atendem clientes via WhatsApp, Telegram e widget web — com base de conhecimento própria, múltiplos modelos de IA e CRM integrado.

### 1.2 Para quem

- Empresas que usam WhatsApp e/ou Telegram como canal principal de atendimento ao cliente
- Times de vendas e suporte que precisam escalar atendimento sem aumentar equipe
- Negócios que querem automação de qualificação de leads com IA.
